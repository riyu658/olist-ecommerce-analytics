# olist-ecommerce-analytics
# 🛒 Brazilian E-Commerce (Olist) Exploratory Data Analysis

A comprehensive end-to-end Exploratory Data Analysis (EDA) of Brazilian e-commerce operations using the Olist Public Dataset. This project uncovers actionable business insights across commercial performance, customer purchasing dynamics, logistics turnaround, and review sentiment.

---

## 📌 Project Overview & Objectives

E-commerce marketplaces thrive on the synergy between supply, demand, and logistics. This analysis explores ~100,000 anonymized orders fulfilled between 2016 and 2018 across Brazil, diagnosing operational bottlenecks and identifying high-margin opportunities.

**Primary Objectives:**
* **Commercial Performance:** Track gross sales, order volume fluctuations, and category concentration.
* **Customer Behavior:** Profile regional demand, payment preferences, and retention patterns.
* **Logistics & Fulfilment:** Quantify delivery lead times, estimate delays, and evaluate shipping cost impacts.
* **Customer Experience:** Analyze correlation between delivery timelines, review scores, and freight ratios.
